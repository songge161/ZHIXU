# AI 规划提案接入

更新时间：2026-10-14。

## 当前实现

`/planner/ai` 已实现本地原型的完整提案闭环：用户描述调整意图，开发服务器根据 `/settings` 当前连接调用 Responses 或 Chat Completions 接口请求严格结构化输出；浏览器再次校验操作类型、字段长度和容量，再展示逐项选择界面。只有用户点击“采纳所选”后才原子替换浏览器工作区。

支持的操作对象为方向、行动、资料、草稿和回顾；支持新增、调整和删除。AI 不允许自动填写行动完成事实。新方向和新行动可以在同一提案中使用临时 ID 建立引用，采纳时转换为本地稳定 UUID。

官方资料：[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)、[Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)。

## 本地配置

连接配置直接在 `/settings` 管理，可保存多个连接并选择当前连接。每条连接包含：

- 显示名称、启用状态和当前选择状态。
- 协议：`OpenAI Responses` 或 `OpenAI Chat Completions`。
- Base URL：例如 `https://api.openai.com/v1`、`https://openrouter.ai/api/v1`、`http://127.0.0.1:11434/v1`。
- 模型 ID 和 API Key；本地模型服务可以留空 API Key。

系统按标准协议补全 `/responses` 或 `/chat/completions`。原型阶段连接配置保存在当前浏览器设置中，API Key 不写入 Markdown 工作区、计划数据或构建产物；正式版应改为服务端加密保存。连接验证不是所有服务都必须支持的能力，因此首期以一次真实提案请求作为可用性验证，并保留服务不实现 `/models` 的兼容空间。

## 安全与数据边界

- 请求只在用户点击生成时发出，并包含当前资料深度档位产生的上下文以及带稳定 ID 的结构化记录。前端先生成 compact workspace：行动总结、资料摘录、草稿和回顾按标准、高、最高档控制数量与长度，不直接把整个工作区原文发送给模型。用户可以选择整个工作区或某个节点作为跟进范围；选择节点时只发送该节点及所有后代节点、行动，范围外的已有记录不会进入工作区载荷。
- 材料正文被明确视为不可信数据，不能改变系统规则或触发工具。
- 输出最多 12 个操作；浏览器端再次限制数量、字段长度、枚举、引用和总工作区容量。
- 未选择的操作不应用；提案生成失败不改变现有数据。
- 方向删除会连同当前模型中归属于它的行动删除，因此无论手动还是 AI 提案都必须明确确认。
- 空间新增和调整可以携带 `parentId`、`kind`，用于创建或移动目标树节点；行动新增和调整可以用 `fields.text` 保存可继续编辑的行动总结。
- 空间和行动的提案还可以携带 `weight` 与 `difficulty`，分别表示同层分量和完成难度；AI 只提出建议，用户确认后才改变评估口径。
- 范围内 AI 只允许调整范围内的空间和行动，新增空间必须挂在范围内父节点下；前端应用提案时会再次检查范围，拒绝范围外的操作。
- 当前资料、草稿和回顾还没有 `spaceId` 归属字段；选择具体范围时它们暂不发送，待资料关联模型建立后再按方向纳入。

## 2026-11-02 实现校准

当前版本已为资料、草稿和回顾保留 `spaceId`，资料可以直接绑定到方向、子方向或行动；按具体范围生成 AI 上下文时，优先纳入范围内资料、行动关联资料和上级资料库，是否包含总文件库由用户选择。原型仍只在本地开发服务器代理请求，API Key 保存在浏览器设置中，生产版必须迁移到 EDU 后端加密配置。

## 生产部署

Vite 中间件只服务本地原型。正式上线时部署 EDU 专用的 `/api/edu/ai/proposal` 服务，沿用当前请求、JSON Schema、提案校验和确认应用协议。它可以和 HomeCC Java API 部署在同一基础设施中，也可以作为独立服务运行，但代码模块、模型提供商配置、密钥、模型白名单、配额和审计记录均由 EDU 单独管理。

该服务不调用或复用主站聊天接口，不继承主站的 DeepSeek 默认配置，不读取主站用户 AI 凭证，也不套用主站聊天业务的计费行为。登录身份和 JWT 可以复用 HomeCC 账号体系；经授权的规划数据可以继续存入现有数据库。这两项复用不改变 AI 服务的独立边界。

生产版还需要保存提案本身、基础修订号、用户选中的操作和应用结果；服务端重新验证权限、记录归属、依赖环及乐观锁，不能信任浏览器已经完成的校验。
