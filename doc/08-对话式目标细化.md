# 对话式目标细化

## 1. 用户要求

用户希望通过与 AI 持续讨论，逐步生成、细化学习内容和目标。对话是规划的核心入口；不要求用户先想清楚全部目标再填写表单。以下为待实现设计。

## 2. 从讨论到计划

流程可随时来回调整，不要求每次走完：

想法或资料 → 澄清方向 → 候选目标 → 阶段成果 → 具体学习内容 → 近期行动 → 执行证据与评估 → 再讨论调整。

- 用户可以先说“研究生阶段想加强研究能力，但还没定题”，AI 先整理兴趣、现状和未知问题。
- 每轮只追问当前最影响选择的一两个问题，允许回答“不确定”或暂时跳过。
- 提供少量可比较的方案及取舍，允许探索后再定目标，不强迫立即量化。
- 用户说“这一块展开”“先不考虑这个”“把难度降一点”时，只更新相关分支，保留其他草稿和已确认内容。
- 学习内容可包含主题清单、概念解释、练习建议、实验步骤、阶段成果和验证任务；引用的外部资源需要可核验来源，无法核验则标为待查。
- 远期保持方向，近期按可投入时间细化；期限、学习预算和掌握程度未知时不凭空补成事实。

## 3. 对话与结构化草稿并行

建议页面左侧讨论、右侧目标树与内容卡片；可从任一节点发起“继续讨论 / 展开内容”。移动窄屏可切换两个视图，根门户布局不变。

AI 在讨论过程中持续整理草稿，不要求每轮点击确认。草稿明确区分用户已表达的约束、AI 假设、候选方案和待回答问题。目标卡片可手动编辑，人工修改和锁定优先保留。

讨论内容不自动变成正式任务。用户选择“把这些加入计划”后，一次预览并确认选定变更；可部分采纳，剩余内容继续讨论。已经明确确认过的同一批次不重复要求确认。后续修改已采纳目标时生成新的变更提案，不悄悄覆盖执行历史。

## 4. 接续与本地使用

每个讨论关联学习空间和可选目标节点，并维护精简的讨论摘要：用户目标、已确认决定、个人约束、待定假设、未决问题、当前草稿及引用材料版本。

允许暂停、跨会话续谈和探索备选方案。摘要能回查相关对话或证据；新讨论优先加载当前草稿与必要材料，不反复发送全部历史。输入范围可由用户查看和选择。

本地助手也使用同一草稿与变更格式：读取所选工作区 → 多轮讨论 → 更新本地草稿和接续摘要 → 导出标准变更包 → 网站预览应用。用户可选择同步摘要而非整段聊天；无需网站模型 API Key 即可导入。续谈仍需要实际提供或授权访问相应文件，不能假定新会话天然知道历史。

## 5. 与能力评估的衔接

目标确定时可共同讨论“什么表现算达到”，例如能够独立复现一个实验并解释差异。暂时无法定义的指标保留待定。

AI 生成的讲解、答案和学习计划是学习内容，不作为用户已经掌握的证据。后续通过用户自述、独立成果、练习和反馈逐步评估；评估结果再帮助决定下一次讨论是补基础、改路径还是提高难度。

## 6. 首期范围与验收

首期覆盖单个学习空间内的多轮讨论摘要、可编辑目标草稿、局部分支细化、部分采纳、标准包导入导出和手工续谈。网站内流式讨论可随后接入同一格式；备选方案先保留独立草稿，不必立即实现复杂分支合并系统。

验收：模糊输入可开始；不确定条件不会被填成已确认事实；人工改动不被下一轮抹掉；只展开选中分支；未采纳草稿不计入正式进度；生成的学习内容不计作掌握证据；采纳幂等；过时草稿应用前检测修订冲突；续谈摘要与材料均遵循账号隔离和测试批次清理规则。
