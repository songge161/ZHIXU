## 1. 方法与范围

- **自动化回归**：项目自带 Playwright 全量套件（含本轮新增的 `material-questions.spec.ts`、`material-library.spec.ts`、`daily-actions.spec.ts`、`proposal-budget.spec.ts`、`schedule.spec.ts`），结果 **75/75 通过（2.8 分钟）**。
- **构建验证**：`vue-tsc --noEmit && vite build` 通过，详见第 7 节的分包数据。
- **黑盒操作**：每个场景使用全新的浏览器上下文（不触碰已有浏览器工作区），覆盖新建/删除/撤销、筛选、问答、导入、校验、删除确认、抽屉与焦点。
- **几何度量**：`/`、`/planner`、`/planner/today`、`/planner/schedule`、`/planner/materials`、`/planner/ai`、`/planner/reviews`、`/planner/sync`、`/settings`、`/planner/spaces/research` 共 10 条路由，分别在 1440×1100、768×1024、390×844 下统计横向溢出、文字裁切、触控尺寸、对比度与兄弟区块重叠。
- **说明**：折叠 `<details>` 内的内容仍保留布局矩形，会制造"重叠"假象；已排除，展开后复测无重叠。本轮所有截图存放在 `output/ux2-*.png` 供人工复核。

## 4. 布局与视觉检查

### 4.1 稳定性结论（好）

- 三档视口 × 10 条路由：**横向溢出全部为 0**。
- 真实重叠：**0**。空间详情页最初检出的 8 处重叠均来自折叠的 `<details>` 内部（`content-visibility` 下的保留布局），展开验收区块后复测为顺序排列。
- 文字裁切：仅 `sr-only` 标签（预期）与门户装饰性轨道图（`aria-hidden`）两处，无内容丢失。
- 弹窗：390px 下删除确认框 358×214，完整落在视口内；长表单弹窗 814px 高、内部滚动，操作区可达。
- 抽屉：宽 225px，scrim 右侧可点击关闭，结构与焦点管理正确。

### 4.2 资料库页的内容优先级（需调整）

390×844 视口下，页面各区块起始位置：

| 区块 | 起始 y |
|---|---|
| 工具栏（资料库 + 搜索） | 247 |
| 本地保存状态行 | ~470 |
| 导入区 | 530 |
| 「问资料」面板 | 847 |
| 「资料」列表标题 | 1085 |
| 第一张资料卡 | 1135 |

第一份资料出现在**首屏之外约 1.3 屏**。在未配置 AI 时，「问资料」仍占据一整块不可用面板，进一步把主内容下推。资料库的第一任务应是"看资料"，当前顺序是"工具 → 导入 → 问答 → 资料"。

建议：工具栏 → **资料列表** → 次要入口（导入 / 问资料）。导入与问答默认折叠为两个入口按钮；未配置 AI 时隐藏或折叠问答案板，只保留一句「配置 AI 后可基于资料问答」。

### 4.3 新组件自身布局

- 390px：问答表单输入 316×46，按钮换行到下一行（114×42），无压缩；上传区 287px 高，图标、文案、按钮正常换行。
- 768px：问答输入与按钮同排；资料工具栏两列、底部对齐。
- 调整历史摘要 320×37 自动换行，撤销按钮 114×42。
- 提案预算的明细 `select` 与 `pre` 无横向溢出，JSON 预览最大高度 18rem 内部滚动。

## 5. 视觉与可访问性问题

### P1-1 标注文字对比度仍系统性偏低

`--readable-muted: #52634e` 令牌已建立，但新老组件中大量硬编码浅绿色绕过了它。实测（12px 常规字重，要求 4.5:1）：

| 选择器 | 前景色 | 实测对比度 | 出现位置 |
|---|---|---|---|
| `.tiny-badge` | `#9aa78b` | **2.28** | 资料类型、「AI 规划」、日程估算等 |
| `.demo-label` | `#b4ab8b` | **2.30** | 资料卡「示例」 |
| `.material-meta` | `#a4ad98` | **2.33** | 资料日期 / 大小 |
| `.count-pill` | `#9aa78b` | **2.28** | 今日行动计数 |
| `.nav-label` | `#a0a794` | **2.43** | 侧栏分组标题 |
| `.add-row` | `#9aa58c` | **2.58** | 「留一个小行动给今天」 |
| `.back-portal` | `#959e8c` | **2.72** | 「教育空间首页」 |
| `.prototype-badge` | `#8b977d` | **2.85** | 「本地原型 · 示例可编辑」 |
| `.ai-compose-foot span` | `#87977a` | **3.12** | AI 页底部说明 |
| `.directory-box p` | `#a1ae8f` | **2.21** | 设置页目录说明 |
| `.prototype-note p` | `#a7b099` | **2.25** | 设置页「关于目录结构」 |
| `.path-examples` | `#7a8f68` | ~3.4 | 设置页目录结构示例 |
| `.section-number`（门户分区） | `#89917d` | ~3.1 | 「01 / AVAILABLE」等 |

这些文字大多是**状态与来源信息**（示例、类型、日期、当前选中范围），并非装饰；在普通屏幕或移动端户外场景会直接丢失。建议一次性把上述选择器收敛到 `var(--readable-muted)` 或新的三级文字色（如 `#5f6f5c`），并把"必须靠颜色区分状态"的地方补上图标或文字。

### P1-2 独立文字按钮的触控高度不足

390px 视口实测：

| 控件 | 尺寸 | 位置 |
|---|---|---|
| `.task-duration`（时间 · 调整） | 85×19 | 今日行动每行 |
| 资料卡「调整 / 删除」 | 24×19 | 资料库卡片 |
| `.back-portal` | 164×17 | 工作区各页左上 |
| 设置页「载入示例 / 清空工作区」 | 96×19 | 设置底部 |
| 日程「在这天添加 / 管理基线」 | 80×19 / 91×19 | 日程页 |
| 详情页 summary（计算明细等） | 17–20 高 | 方向详情 |
| toast「撤销删除」 | 60×24 | 全局提示 |

任务行的 checkbox 本身 19×19，但外层 label 有 44px 命中区，可接受；以上这些是**独立按钮**，没有扩展命中区。建议统一 `min-height: 32px`（桌面）/ `44px`（≤760px），用 padding 或伪元素扩展，不改变视觉字号。

### P2 级问题

1. **11px 小字回归**：资料库方向选择器的说明文字（「查看所有资料库」「通用资料，可在 AI 中选择引用」）为 11px（`DirectionPicker.vue` 的 option `small`），上传区说明「可先导入…」为浏览器默认 `small` 的 11.67px。新内容应遵守已建立的 12px 下限。
2. **禁用原因离按钮太远**：AI 未配置时，「根据资料回答」「生成 AI 导读」为禁用态，但解释文字分别位于面板上方或上传区；建议在禁用按钮旁直接标注「需先在设置配置 AI 接口」。
3. **撤销入口的可发现性**：删除后的 5 秒 toast 提供「撤销删除」，一旦错过，需要到设置 → 调整历史 → 展开第一条才能撤销。建议在历史卡片顶部增加常驻的「撤销最近一次调整」按钮（仍可保留展开明细）。
4. **弹窗焦点回环**：模态框每轮 15 个 Tab 落点中有 1 次落在 `BODY`（原生 dialog 循环边界），进入下一轮恢复正常；建议加起止哨兵或在文档中接受该行为。
5. **标题口径不一**：`/planner/materials` 的页面标题与侧栏为「资料与证据」，页内 H1 为「我的资料库」；两者都对，但建议统一为同一名词。
6. **长页面密度**：390px 下资料库 1983px、设置 2668px。本轮新增内容多为主页外挂面板，建议把「导入」「问资料」「调整历史」做成折叠/独立分区，减少首屏外推。

## 6. 建议的实施顺序

**第一步：两天内（视觉与触控清零）**

1. 低对比度选择器统一替换为 `var(--readable-muted)`；把 `.tiny-badge`、`.demo-label`、`.material-meta`、`.nav-label`、`.add-row`、`.back-portal`、`.prototype-badge`、`.directory-box p`、`.prototype-note p`、`.ai-compose-foot span` 一次性覆盖。
2. 独立文字按钮统一最小高度（桌面 32、移动 44）；覆盖 `.task-duration`、资料卡操作、`summary`、设置底部文字按钮与 toast 撤销。
3. 设 12px 字号下限：`DirectionPicker` 的 option `small` 提到 12px；上传区 `small` 显式 12px。

**第二步：资料库信息架构（半天到一天）**

4. 调整顺序为「工具栏 → 资料列表 → 导入/问答」；导入与问答默认折叠，未配置 AI 时只保留配置提示。
5. 在禁用按钮旁补一行原因；在调整历史卡片顶部常驻「撤销最近一次调整」。
6. 统一「资料与证据 / 我的资料库」的命名。

**第三步：把检查固化为测试**

7. 将对比度与最小触控尺寸加入自动检查（可在 Playwright 中对关键选择器断言 `getComputedStyle` 与 `getBoundingClientRect`）。
8. 保留 360–1920 八档布局回归；新增资料库首屏内容位置的断言，防止主列表再次被推到折叠线以下。
