# 新会话接手说明

## 已确认要求（2026-10-13）

- 项目目录为 `homecc/edu-combinecalculate`，与 `homecc-javaapi` 同级。
- 独立子网站，先本地验证，之后再接入 `edu.combinecalculate.cn`；不做小程序。
- 根首页预留未来教育门户，个人规划是 `/planner` 附属栏目。
- 存储设置放在 `/settings`。用户手动选择目录，不读取或生成设备序列号；数据身份来自每条记录的稳定 ID，与 Mac、Windows 或浏览器无关。
- 本地工作区按记录保存 Markdown，以 TSV 保存有效记录索引和关系边，不用一个 JSON 文件承载全部数据。
- 规划覆盖研究生阶段、大领域学习、考研、语言阶段、单学科、论文项目和日常习惯。
- AI 讨论要能从模糊想法逐步形成目标、学习内容与行动，支持局部分支、暂停续谈和部分采纳。
- EDU AI 使用独立提案协议、接口和配置，不复用主站聊天接口、DeepSeek 默认配置或用户 AI 凭证体系；设置页支持多个 OpenAI 兼容连接，HomeCC 账号、JWT 和数据库仍可作为公共基础设施复用。
- 用户会逐步补充文件、成果和自述；评估须保留证据来源、历史及分歧，不能用任务完成率冒充能力水平。
- 双端同步必须控制历史、附件和操作日志增长；阶段摘要按图邻域选取上下文，并提供标准、高、最高三档策略。
- 已将可选的 macOS / Windows 桌面同步助手列入后续日程。两端共用一套跨平台同步核心，只分别适配打包、签名和系统权限；网页跨设备同步本身仍通过 HomeCC API 完成。
- 未来复用现有线上数据库及同级 HomeCC Java API。测试痕迹默认在转线上前清理，并保护主站数据和真实个人资料。

## 已完成与尚未实现

Vue 3 + TypeScript + Vite 本地原型已经具备教育门户、方向总览、方向详情页、行动管理、资料、自述、草稿、小结、日程及 Markdown 接续包。方向、计划、阶段、项目、分支、行动、推进记录、资料、草稿、回顾和日程均可调整或删除。节点通过 `parentId` 组成归属树，节点和行动都能设置分量与难度；行动可挂在任意节点，完成度按加权和上层递减曲线计算。`/planner` 只展示根方向，`/planner/spaces/:spaceId` 展示一个方向的子方向目录和直接行动，可从这里继续发散。行动总结可以在表单中修改，或从 Markdown/TXT 文件导入。`/planner/ai` 通过本地服务器调用 AI，生成严格结构化的新增、调整和删除提案；AI 可以选择整个工作区或当前节点及其后代作为范围，详情页能直接带范围进入，用户可以逐项取消并在确认后原子应用。设置页可以手动选择目录，将业务记录分别写为 Markdown；`_index.tsv` 保存内容哈希，`graph/edges.tsv` 保存节点、行动、推进记录、资料和日程关系。

尚未接入账号或 EDU 后端、未建表、未执行迁移、未实现目录监听、云端同步、三方合并、语义摘要或正式部署。AI 当前是本地开发服务器代理，生产时部署 EDU 专用 AI 提案服务。当前已完成目标树、固定关系边、资料与证据绑定、证据等级、加权执行进度和日程预算；通用图关系、可验证能力评估和云端版本合并仍未完成。完整演进方案见 `12-目标图与增量工作区设计.md`，AI 接入边界见 `13-AI规划提案接入.md`。

2026-11-02 整体巡检：`npm run build` 通过；Playwright 全量回归 33 项全部通过。后续开发应把本地可持续使用与线上化边界分开，先稳定同步协议和数据清理规则，再接 HomeCC API。

接手时先读 README 及 `04`、`05`、`07`—`12`。本目录最新文档优先于主站中的旧立项草案。修改同级后端前读取其仓库说明并检查工作区，避免覆盖主站和微信登录等其他工作的未提交改动。
