# 页面结构与操作路径

2026-10-14：整理本地原型的导航和操作层级。

| 页面 | 职责 |
| --- | --- |
| `/` | 教育门户，保留未来课程与研究入口 |
| `/planner` | 大方向总览，手动创建大方向 |
| `/planner/spaces/:spaceId` | 当前方向进度、子方向目录、当前方向直属行动 |
| `/planner/today` | 跨方向的今日行动、后续安排和想法草稿 |
| `/planner/schedule` | 日/周/月日程、生活基线、节假日与剩余时间预算，详见 [19](19-日程与时间预算.md) |
| `/planner/ai` | 选择大方向，再选择子方向，生成并审阅提案 |
| `/planner/materials` | 学习资料与自述证据 |
| `/planner/reviews` | 阶段回顾 |
| `/planner/sync` | 讨论接续与目录读写 |
| `/settings` | 目录、上下文质量、AI 接口等配置 |

总览卡片点击进入详情，编辑入口独立。子方向继续使用同一详情路由，通过面包屑回到上级。详情页创建子方向和行动时自动带入当前方向。节点类型（阶段、计划、项目等）是内容分类，大方向和子方向由父子关系决定。

AI 的子方向选项仅显示所选大方向内的分支；整个大方向包含其下级。切换范围会清除旧提案，请重新生成。请求过程中禁用范围选择，并丢弃范围已改变的响应。AI 默认细化已有方向，创建新大方向仍需用户明确要求。

本次提取 `DirectionOverview.vue`，其余页面暂保留在 `App.vue`。未迁移存储格式，未调整进度算法，未接入线上服务。后续拆分页面组件时应沿用上表边界。
