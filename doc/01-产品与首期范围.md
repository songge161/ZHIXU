# 产品与首期范围

## 1. 首期问题

用户有长期学习目标，但日常任务容易脱离目标；计划遇到实际阻碍后又缺少低成本、可回溯的调整方式。

## 2. 首期闭环

1. 从想法或材料开始：用户可以只描述兴趣、困惑或方向，无需预先填写完整目标、截止时间和时间预算；讨论先保存为草稿。
2. 通过多轮 AI 讨论逐步澄清目标、现状和约束，形成可编辑的目标、里程碑、学习内容与验证方式；支持只细化某一分支，也可完全手工建立。详细流程见 `08-对话式目标细化.md`。
3. 生成提案：优先用本地资料和可访问文件的 AI 助手整理为标准变更包，也可选择网站 API；输出近期计划及修改理由，不直接写入正式数据。
4. 用户调整并应用：可编辑、移动、删除、补充计划项；确认后生成新计划版本。
5. 每日打卡：记录投入时长、进展、阻碍和主观感受。
6. 周复盘：AI 基于已授权的本工具数据及可选的 HomeCC 执行数据，提出继续、缩减、延后或重排建议。
7. 持续积累文件、个人成果与自述，按目标标准生成分项评估和多次总评；用户可纠正，后续用新证据复评。详细设计见 `07-学习证据与多层评估.md`。

## 3. AI 规则

- 输出受 JSON Schema 校验的结构化提案。
- 页面必须展示新增、修改、移动和删除的差异。
- 未经用户确认，提案不得改变目标、计划或打卡记录。
- 应用操作只能经过后端白名单业务服务，并保存提案、确认人、输入版本和结果审计。
- 用户可以完整手动管理数据；AI 的权限始终低于用户。

## 4. 首期验收

- 用户能创建一个学习空间、目标和手工计划。
- 用户能查看和恢复历史计划版本。
- AI 提案可以逐项编辑，确认前后数据差异可见。
- 多个 HomeCC 用户之间严格隔离数据。
- 关联或取消关联每日任务，不会损坏长期计划历史。
- 无模型 API Key 时，仍可通过本地导入、手工编辑和导出完成完整规划闭环。
- 同一模型覆盖长期方向、阶段目标、学科、论文项目与具体任务；习惯按重复规则和实际记录呈现。
- 计划调整保留完成记录、成果和历史版本；锁定项不被后续 AI 重排覆盖。
- 用户可以从模糊想法开始多轮讨论，随时暂停、续谈和改变方向；草稿自动整理，选定内容可一次确认纳入计划，未确定内容保持待讨论。
