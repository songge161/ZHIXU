# 项目定位与边界

## 1. 定位

Edu CombineCalculate 是未来教育门户的项目容器，首页可逐步发展成类似大学网站的栏目入口。个人学习与进度管理是附属栏目，使用 `/planner`，不能把根首页固定成个人计划看板。门户的院系、课程等具体栏目尚未确定。

规划栏目帮助用户把研究生阶段、大领域学习等长期方向，拆成考研或语言阶段、学科、论文项目及近期行动，并根据真实投入与记录持续调整。

产品的核心不是“AI 自动替用户安排生活”，而是让用户能看见计划与现实的差异，并始终保有最终调整权。

## 2. 站点边界

| 站点或服务 | 职责 |
| --- | --- |
| `www.combinecalculate.cn` | 主站内容、产品入口与介绍 |
| `edu.combinecalculate.cn/` | 未来教育门户首页 |
| `edu.combinecalculate.cn/planner` | 私人目标、计划、打卡、复盘和进度视图 |
| `api.combinecalculate.cn` | HomeCC 账号、鉴权、进度模块与受控数据访问 |
| EDU AI 提案服务 | 规划上下文整理、结构化提案生成及独立 AI 配置与审计 |

Edu 前台独立开发、独立构建和独立部署。账号、Token 和业务数据库连接可复用 HomeCC 基础设施；AI 服务使用 EDU 自己的接口、密钥和模型配置。

## 3. 与现有 HomeCC 的关系

- 使用现有 HomeCC 用户 ID 作为数据归属。
- 可按用户授权只读关联现有 `plan_tasks` 与 `focus_sessions`，用于展示真实执行情况。
- 长期目标、计划版本、AI 提案和进度打卡属于新领域模型，不直接塞入现有每日计划表。
- 首期采用独立登录会话；需要跨子域无感登录时，再升级现有 SSO 为受限的浏览器授权码流程。
- 本地资料与 AI 整理结果可作为规划输入；网站 API 调用为可选功能，不是创建和维护计划的必要条件。

## 4. 不在范围内

- 小程序版本。
- 群组协作、课程市场、付费、自动通知和外部日历双向同步。
- AI 未经确认直接修改计划、删除数据或调用任意接口。
