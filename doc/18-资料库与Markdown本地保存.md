# 资料库与 Markdown 本地保存

2026-10-14 · 本地原型已实现

## 使用路径

1. 在大方向或子分支详情点「资料库」，进入该方向的资料列表。
2. 点「写 Markdown」，填写标题、所属资料库和正文；也可以导入自己的 `.md`、`.txt` 文件。
3. 保存时，已绑定目录会默认勾选「同时写入目录」；未绑定目录则默认勾选「同时下载 .md 文件」。可以取消勾选，只保存浏览器记录。
4. AI 页展开「本轮将参考…份资料摘要」，查看这次真正选中的资料名称；必要时勾选「同时参考总文件库」。

可用的写作起点：[学习笔记模板](./templates/学习笔记模板.md)。下载或复制模板后，在自己习惯的编辑器中写作，再导入目标资料库。

## 资料如何归属

| 入口 | 内容 | 新建和导入时的默认归属 |
| --- | --- | --- |
| 全部资料 | 汇总所有方向与总文件库 | 总文件库 |
| 总文件库 | 没有绑定具体方向的通用资料 | 总文件库 |
| 大方向资料库 | 当前方向资料，可包含下级 | 当前大方向 |
| 子分支资料库 | 当前分支资料，可包含下级 | 当前子分支 |

「包含子分支」只影响列表筛选，不改变新资料的归属。在资料编辑窗口更换「所属资料库」即可移动归属，记录 ID 和正文保留。总文件库与全部资料有不同含义：前者是实际归属，后者是汇总视图。

物理文件仍按稳定 ID 存放在 `evidence/<id>.md`，归属写在文件头的 `spaceId` 和 `graph/edges.tsv` 中。调整名称或所属方向不会导致反复移动、复制正文。

## AI 的读取规则

选择某个方向时，按以下优先级选取资料，同级按更新时间排序：

1. 当前方向及其下级资料库。
2. 当前方向的上级资料库，用于共享学习目标、说明或教材笔记。
3. 勾选「同时参考总文件库」后，再考虑通用资料。

其他大方向和兄弟分支的独立资料不带入。选择整个工作区时，所有资料库都可以参与取样。上级与总文件库资料在子范围中只作参考，提案的修改权限仍受方向范围约束。

| 档位 | 最多选取资料 | 每篇在结构化请求中的正文上限 |
| --- | --- | --- |
| 标准 | 3 篇 | 500 字符 |
| 高 | 8 篇 | 1,400 字符 |
| 最高 | 15 篇 | 2,600 字符 |

讨论接续包也会带摘要（标准 500 / 高 1,800 / 最高 3,000 字符），两处都明确标注截短与未包含的资料。完整正文保留在浏览器记录及本地 Markdown 中，不会因切换质量档位而删减。当前为按范围、日期取样，还没有语义检索或自动选择正文中间的相关段落。

## 本地保存与冲突

- 写笔记和编辑资料可以同时写入已选工作区目录。导入资料后，有已选目录时也会尝试写入。
- 写入使用现有多文件工作区流程，也会保存当前目标树等关联记录，以便恢复资料归属；仅内容哈希变化的文件会重写，索引最后更新。
- 自动写入前检查索引及记录。发现手工修改、文件缺失、目录独有记录或同名未登记文件时暂停，并显示原因；浏览器中的修改保留，可核对后重试。
- 如果本地文件已修改，可在设置使用「从目录读取」。当前读取是确认后的整份工作区替换，不是字段级合并；应先下载需要保留的浏览器笔记再替换。
- 没有目录时，新建/编辑笔记可直接下载 Markdown；每张资料卡也有「下载 Markdown」。浏览器负责下载目的地。
- 文件中包含记录 ID、名称、归属等元数据，正文为 Markdown。通过目录读取时会保留这些关联；普通文件导入作为新资料登记。
- 目录自动写入失败不等于保存成功，资料页持续展示失败状态和重试入口。没有文件监听、云端同步或跨设备冲突合并。

## 当前容量与格式边界

每份文本最多 100,000 字符，最多 50 份资料。导入文本先检查文件大小（400,000 字节）及字符数，超过限制时拒绝整批导入，不静默截断。浏览器存储容量由浏览器决定；存储失败仍会显示全局提示。

Markdown、TXT、CSV 读取正文。PDF、图片等只登记文件名、大小等信息，原二进制文件不复制、不解析；下载出来的是对应 Markdown 信息记录，AI 看不到原文件内容。此限制在资料导入入口明确展示。

## 验证

自动化验证包含：长 Markdown 的完整保存与下载、归属移动和筛选、上级资料继承、总文件库开关、AI 请求长度控制，以及向隔离测试目录写入后保护手工修改。测试未调用付费模型，未写入用户绑定的真实目录。
