# Edu CombineCalculate

面向未来教育门户的独立子网站，首个功能栏目为个人学习与进度规划。本项目在本地完成验证后，计划以 `edu.combinecalculate.cn` 发布。根路由 `/` 预留给教育门户，规划工具位于 `/planner`。

## 当前阶段

- 阶段：已完成 v0.1 本地可交互原型（规划、资料、证据、回顾、AI 提案和日程），尚未上线。
- 前端：独立站点，不纳入现有个人网站的路由和导航。
- 后端：后续计划复用 `../homecc-javaapi` 的 HomeCC 账号、鉴权和数据能力，当前原型没有调用后端。
- 数据库：后续沿用现有线上数据库；本轮未连接数据库、未建表、未执行迁移。浏览器保存运行缓存，用户可手动写入多文件目录工作区。
- 小程序：不在范围内。

2026-10-13：已实现 Markdown 讨论接续包，以及手动选择目录后的多文件工作区。目标、行动、证据、草稿和回顾分别保存为 Markdown；TSV 索引记录 SHA-256 并在最后提交，关系表为目标图预留入口。目录读取仍是确认后的整体替换。文件监听、云端同步仍属后续工作。

2026-10-14：已实现首版多层规划：方向、计划、阶段、项目和分支通过 `parentId` 组成目标树；每个节点可以继续细化并独立安排行动。行动支持直接编辑总结，也支持导入 Markdown/TXT，内容写入 `actions/<id>.md`。AI 请求按标准、高、最高三档压缩行动总结和资料摘录后发送，避免把整个工作区原文重复塞入上下文。

同日加入首版加权评估：行动和节点都可以设置 1–100 分量与 1–5 难度。节点有直接行动时，基础行动执行占 60%，下级节点按分量汇总占 40%；方向、计划等上层节点使用递减曲线，完成难度越高越不会被大量简单行动虚高。该分数是可解释的执行进度，不等同于能力评估。

规划入口区分大方向和子方向：总览中的“新建大方向”用于手工建立顶层容器；进入方向详情后使用“新建子方向”。AI 提案默认在已有方向下继续拆分，只有用户明确要求时才创建新的大方向。

已列入后续日程：先用 HomeCC API 实现网页跨设备同步；协议稳定后增加可选的跨平台桌面同步助手，用一套核心支持 macOS 和 Windows，负责本地目录监听、离线队列与文件和云端之间的增量传递。

2026-10-13：本地原型已增加 `/planner/ai`。AI 生成方向、行动、资料、草稿和回顾的结构化调整提案，用户逐项选择后才应用；现有记录均可继续手工调整或删除。现在可以选择整个工作区、某个方向或任意子分支作为 AI 跟进范围，详情页也能直接带着当前方向进入 AI。当前 AI 代理运行在本地 Vite 开发服务器，正式上线时部署 EDU 独立 AI 提案服务，不复用主站聊天接口、DeepSeek 配置或用户 AI 凭证体系。

## 本地启动约定

需要 Node.js 22.12+，当前验证环境为 Node.js 22.19。首次执行 `npm ci`，然后：

```sh
npm run dev
```

- 教育门户：http://127.0.0.1:4180/
- 规划工作台：http://127.0.0.1:4180/planner
- 方向详情示例：http://127.0.0.1:4180/planner/spaces/research
- AI 规划：http://127.0.0.1:4180/planner/ai
- 设置：http://127.0.0.1:4180/settings

验证命令：`npm run build`；`npm test`（使用本机 Google Chrome，测试在临时隔离浏览器中运行）。

本地 AI 在 `/settings` 中配置，可保存多个 OpenAI 兼容连接并选择当前连接；支持 Responses 和 Chat Completions 两种协议。密钥只用于本机开发服务器代理请求，原型阶段保存在当前浏览器设置中，不要写入工作区或提交到仓库。正式版改为后端加密保存。详细协议见文档 `13`。

Mac 与 Windows 分别执行相同命令，在设置中手动选择各自可访问的工作区目录。数据记录使用稳定 ID，不依赖设备序列号；可以通过双方都能访问的同步文件夹传递，也可以手动复制目录。开发时打开门户 `/?lan=1` 可显示局域网测试链接。

开发脚本当前临时使用 `0.0.0.0:4180` 提供局域网页面测试入口；该入口只用于本地验证，目录读写仍需在本机 `http://localhost:4180` 或 HTTPS 安全上下文中授权。正式构建不包含局域网测试链接。

手工规划和目录工作区无需 API Key、账号或线上数据库；使用 AI 规划时在 `/settings` 选择一个已配置的连接。不得把线上数据库、账号、Token、模型密钥或证书写入仓库。目录管理在 `/settings` 中，详见文档 `11`。
